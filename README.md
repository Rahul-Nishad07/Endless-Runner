# 🎮 Endless Runner

A 3D endless runner mobile game featuring a soldier character navigating a challenging path filled with obstacles and collectible coins.

## ✨ Features
- 3D gameplay powered by Three.js
- Soldier character with running and jumping mechanics
- Three-lane running environment
- Obstacles and collectible coins
- Progressive difficulty and immersive city environment
- Built with React Native and Expo

## 🛠️ Tech Stack
- React Native
- Expo SDK 57
- JavaScript
- Three.js
- Expo GLView

## 🚀 Getting Started

```bash
git clone <YOUR_REPOSITORY_URL>
cd ENDLESS_RUNNER
npm install
npx expo start
```

Use Expo Go or a compatible development build, depending on the project's native dependencies.

## 📦 Android Production Build

```bash
eas build --platform android --profile production
```

## 📁 Project Structure

- `app/` — Expo Router screens
- `src/game/` — game world and gameplay logic
- `src/player/` — player character
- `src/world/` — road, buildings, obstacles, coins, and power-ups
- `assets/` — game assets and images
